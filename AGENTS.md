# AGENTS.md — rules for every AI agent in this repo (Codex, Claude Code, others)

Project: **The Last Voyage**, a co-op pirate real-life-fuelled game (Hack The Nest 2026, 24h).
Read `docs/GAME.md` first. It's the design source of truth.
Codex: then read `docs/CODEX_HANDOFF.md`, which is your brief.

## Who owns what (to avoid merge conflicts)
| Area | Owner | Others may |
|---|---|---|
| `design/**` (specs, mockups, style frames, reviews) | **Codex** | read |
| `assets/sprites/**` + `assets/sprites/manifest.json` | **Codex** (user approves) | read |
| `apps/mobile/src/theme/**` (tokens, typography) | **Codex** | read; propose changes in `design/requests.md` |
| `apps/mobile/src/ui/**` (presentational components, props-only, no data fetching) | **Codex** | Claude may fix type or build errors |
| `apps/mobile/src/app/**` (routes/screens), `src/features/**`, `src/lib/**`, `src/state/**` | **Claude** | Codex may propose diffs in a PR |
| `apps/mobile/modules/**` (native: scroll-sentinel, etc.) | **Claude** | — |
| `packages/game/**` (pure TS rules + tests) | **Claude** | — |
| `server/**` (Mongo API) | **Claude** | — |
| `content/**` (islands, events, quests, narration scripts JSON/MD) | teammates / Codex | Claude validates with zod |
| `docs/GAME.md` | **user** | propose edits only |
| root config (`package.json`, `app.json`, `tsconfig`, lockfiles) | **Claude** | ask first |

**Rule of thumb:** Codex builds *how it looks* (props in, pixels out). Claude builds *how it works* (data, state, native, server) and wires Codex's components into screens.

## Git workflow
- `main` must always build. Never force-push `main`.
- Branches: `codex/<topic>` for Codex, `claude/<topic>` for Claude. Small PRs, merged by the user.
- Commit only files inside your own area. If you need a change outside it, write it in `design/requests.md` (Codex) or `docs/requests.md` (Claude).
- **Never commit:** `node_modules/`, `.env*`, `android/`, `ios/` (generated by Expo CNG), large raw art (>2 MB; keep originals outside the repo or in `design/raw/` via Git LFS only if agreed).
- Only one agent edits `package.json` or the lockfile at a time, and that's Claude. Codex lists needed deps in `design/requests.md`.

## Commands (run from `apps/mobile` unless noted)
```bash
npm install                 # at repo ROOT only (npm workspaces)
npx expo install <pkg>      # never `npm add` for Expo/RN packages
npx tsc --noEmit            # typecheck — must pass before a PR
npx expo lint               # lint — must pass before a PR
npx expo start              # dev server (the dev build on the phone connects to it)
npm test -w @last-voyage/game   # game rules tests (root)
```
Expo changes every SDK. Check versioned docs (`https://docs.expo.dev/versions/v58.0.0/`) instead of trusting memory. See `apps/mobile/AGENTS.md`.

## Hard rules (non-negotiable)
1. **Sprite approval:** a sprite may only be referenced by app code once `assets/sprites/manifest.json` marks it `"status": "approved"`, and only the user sets that. New sprites start as `"pending"`.
2. **IP:** genre-inspired only. No straw hats, stretch or rubber powers, fruit powers, "Grand Line"-style seas, "Pirate King", "nakama", bounty posters with currency, or lookalike flags/logos/silhouettes of any existing series. Never name a series or artist in prompts. Say "90s–2000s shonen adventure manga style" instead.
3. **Privacy:** no on-screen text capture from other apps. Face photos never go to AI services.
4. **No secrets in the app bundle.** API keys live on the server only.
5. Don't edit `android/` or `ios/`. Configure native via `app.json` and config plugins.
