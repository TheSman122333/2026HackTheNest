# Voyage typography

Bundled locally so typography also works offline, without additional packages.

- **Voyage Serif**: a static weight-600 instance of [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond), by Christian Thalmann.
- **Voyage Sans**: static weight-400, 500, and 600 instances (optical size 14) of [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans), by the DM Sans project authors.

Instances were made with fontTools and renamed to avoid reserved font names. Original copyright notices are retained in the font files. Both families use the SIL Open Font License 1.1; the original licenses are included here.
